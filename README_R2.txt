R2 reproducibility bundle

The authoritative revised Table 3 is generated by scripts/r2_analysis_33174.py. Its k/C search is development-only for holdout evaluation and fully nested for cross-validation. scripts/r2_figures_33174.py generates the seven revised figures. The historical scripts are included for shared helpers and provenance; the R2 scripts define the results submitted in this revision.

Set NSCLC_PROJECT_ROOT to the existing project root containing scripts, public_data, server_results, and outputs. Set NSCLC_PETCT_DATA_DIR to the folder containing the three original PET/CT CSVs if these are stored elsewhere (for example, on F:). NSCLC_REVISION_OUT can override the result directory. No data are downloaded or copied by this bundle.

Run Python scripts/r2_analysis_33174.py, then Python scripts/r2_figures_33174.py. Dependencies used for the numerical rerun: numpy 2.4.3, pandas 2.3.3, scipy 1.17.1, scikit-learn 1.6.1, statsmodels 0.14.6. Figures use matplotlib 3.10.9, seaborn 0.13.2, lifelines 0.30.3 and xenaPython 1.0.14.

Results are a reanalysis of a previously examined holdout; they are not a new external-validation cohort. The fixed k=5/C=3 50-split sensitivity result is not an independent unbiased validation of tuning. Figure 9B contains TCIA estimates only.

This R2 source update accompanies the November 2026 revision. Source code is public; source patient data are not redistributed here. The corrected aggregate outputs are supplied with the manuscript's revised Supporting Information.
